# 이전 단계: 고정 경골 관찰 장치

현재 기본 실행은 공개 초파리 몸체로 바뀌었다. 현재 안내는 [FULL_CNS.md](FULL_CNS.md)다.
이 문서는 당시 가정과 기록을 보존한다. 아래 `scripts/run_full_cns.cmd` 실행 예시를 이전 장치에
적용하려면 `scripts/run_muscle_rig.cmd`로 바꿔 실행한다.

초기 모델에서 기능별 회로를 선정하지 않는다. 공개 MaleCNS 전체 연결표와 모든 주석 뉴런을
포함해 PC의 MuJoCo에서 관찰하고, 기록을 바탕으로 작은 모델의 후보를 추출한다.
라즈베리파이 4에 전체 모델을 바로 탑재하려는 단계가 아니다.

## 실행

1. `scripts/install_navigation.cmd`로 기존 MuJoCo 의존성을 설치한다.
2. `scripts/download_all_cns.cmd`로 공식 flat-connectome 표 7개를 받는다. 기존 파일은 검증 후 재사용한다.
   다운로드가 끊기면 `.part`에서 이어 받는다. 약 24 GB이며 추가 작업 공간도 필요하다.
3. `scripts/run_full_cns.cmd`를 실행한다. 최초에는 전체 그래프를 구성하므로 오래 걸릴 수 있다.
   기존 `run_mujoco.cmd`도 이제 새 전체 모델 실행으로 연결한다.
4. GUI는 일시정지로 시작한다. `Space` 시작/정지, `R` 리셋, `C` 입력 카메라/외부 시점.
   `1` 물체 없음, `2` 밝기 증가, `3` 밝기 감소, `4` 물체 왼쪽 이동,
   `5` 오른쪽 이동, `6` 정면 접근, `7` 움직이는 물체가 있는 자유 관찰.
   조건을 바꾸면 몸체·신경 상태를 초기화하고 정지한다. 다시 Space로 시작한다.
5. 매 프레임 전체 신경 상태와 카메라·입력·출력·몸체 상태가 기록된다.
   기본 저장 한도는 10 GiB, 한도에 도달하면 실험을 종료한다.
   예: `scripts/run_full_cns.cmd --record-gb 20 --glutamate negative`

현재 출력은 **신경 활동 → 굽힘/폄 가상 근육 → 여섯 경골 관절 토크**다.
MuJoCo 창과 별도의 신경·근육·관절 표시 창이 열린다. 두 창 모두에서 조건을 선택하고
Space로 시작/정지할 수 있다. 몸체는 고정된 관찰 장치이며 보행·회피 성능을 평가하는 모델이 아니다.
직사각형 두 다리와 두 모터의 기구가 정해지면 해당 구조의 구동부로 옮기는 단계가 필요하다.

## 가상 근육과 관절 표시

- 모든 CNS 연결과 상태 계산·기록을 유지한다. 출력 읽기만 주석의 경골 근육 기능별로 나눈다.
- `vnc_motor` 중 `fl/ml/hl`과 좌우 주석을 사용한다. 이름에 `Ti flexor` 또는 `Tibia flexor`가
  있는 뉴런을 굽힘, `Ti extensor` 또는 `Tibia extensor`가 있는 뉴런을 폄에 연결한다.
  accessory tibia flexor도 해당 굽힘 그룹에 포함한다. 기능을 확인하지 못한 다른 운동신경은
  전체 모델과 전체 기록에 남으며 임의로 근육에 배정하지 않는다.
- 근육별 입력은 해당 그룹의 평균 활동이다. 그룹이 비어 있으면 입력 0과 주석 누락을 표시한다.
- `target = clip(activity / activity_scale, 0, 1)`이며 기본 `activity_scale=0.0001`이다.
  기존 기록에서 관찰된 출력 크기를 읽을 수 있도록 정한 **공학적 기본값**으로,
  생리학적 보정 완료 값이 아니다. 매 프레임 최대값으로 재정규화하지 않는다.
- 근육 활성은 기본 0.1초 시정수로 target에 접근한다. 최대 근육 힘은 기본 4 N,
  모멘트암은 0.04 m다. `힘 = 최대 힘 × 활성`, `토크 = 모멘트암 × (굽힘 힘 − 폄 힘)`.
  근육 길이·속도에 따른 생리학적 힘 관계나 운동신경별 힘 차이는 구현하지 않았다.
- 고정 몸체의 좌우 앞·중간·뒤 경골 관절 6개를 토크로 구동한다. 양의 각도/토크는 굽힘이다.
  중력과 접촉을 비활성화하고 관절의 복원 스프링·감쇠를 사용한 진단 장치다.
  고정된 대퇴부와 경골 한 관절만 있으므로 실제 여섯 다리 보행이나 두 모터 기구를 재현하지 않는다.
- 표시 창에는 원래 신경 활동, 근육 활성 막대, 힘(N), 토크(Nm), 관절 각도(도)가 나온다.
  DNa02/DNg13 좌우 활동과 차이도 관찰한다. 좌우는 세포체 주석 기준이며,
  교차 투사 방향을 모터 방향으로 간주하거나 이 차이를 회전 명령으로 사용하지 않는다.
- 좌우 전체 운동신경 평균은 진단용 숫자로 남지만 모터 속도로 전달하지 않는다.
  고정 전진, 회피 규칙, LLM, 강화학습은 추가하지 않았다.

근육 변환 계수는 실행 시작 때 고정하고 metadata에 저장한다. 예:

```powershell
scripts/run_full_cns.cmd --activity-scale 0.0001 --muscle-force 4 --moment-arm 0.04 --muscle-tau 0.1 --record-gb 40
```

이전 `--motor-gain` 옵션은 제거했다. 활동 단위를 모터 속도로 바로 바꾸던 출력 대신
위 근육 매개변수를 사용한다. 이 매개변수 보정은 신경망 가중치를 학습시키는 작업이 아니다.

### 무물체 기준과 같은 시점 비교

1. `1` 물체 없음 선택 후 Space로 기록한다.
2. 충분히 관찰한 뒤 Space로 멈추고 다른 조건을 선택한다. 조건 선택은 신경·근육·관절 상태를 초기화한다.
3. Space로 시작하면 초기화 이후 **동일한 신경 업데이트 번호**의 무물체 기록과 차이를 표시한다.
   기준이 없는 시점은 비교 없음으로 표시한다. 비교값은 제어 입력에 사용하지 않는다.
4. 다시 무물체 조건을 선택하거나 그 조건에서 R로 리셋하면 기존 비교 기준을 지운다.
   기준은 같은 실행 세션 안에서만 유지한다. 기준 에피소드 번호와 차이는 매 프레임 기록한다.

밝기 조건은 가상 2초 이후 변화한다. 전체 상태를 매번 저장하므로 기본 10 GiB로는 그 전에
종료될 수 있다. 여러 조건 비교에는 저장 한도를 충분히 늘리고 각 조건의 경과 시간을 맞춰야 한다.

## 공개 데이터 확보 범위

공식 목록: https://male-cns.janelia.org/download/
정확한 파일 목록과 다른 공개 자산은 `data/public_data_inventory.json`에 있다.

- 7개 flat 표: 주석, 뉴런 전달물질, segment 통계, 전체 연결, 시냅스 위치,
  시냅스 파트너, 시냅스별 전달물질 확률.
- 전체 연결표는 기능·hop·최소 weight 조건으로 자르지 않는다. VNC, 운동신경,
  상행·하행·다른 감각 회로와 자기 연결도 보존한다.
- 시냅스 없는 주석 뉴런도 graph ID로 보존한다.
- 미주석 segment는 삭제하지 않지만 완전한 뉴런으로 확인된 것은 아니다.
  이전 집계에서는 약 8,838만 개 graph ID에 상당한 미주석 segment가 포함됐다.
- EM 이미지 볼륨, segmentation, skeleton 파일, Neo4j DB도 공개되어 있지만 이번에
  모두 다운로드한 것은 아니다. 7개 표를 받았다고 모든 공개 자료를 받았다고 부르지 않는다.
- 시냅스 위치·파트너·개별 전달물질 자료는 원본 그대로 보존한다. 현재 point-neuron
  모델은 전체 연결표와 뉴런 단위 전달물질 집계를 동역학에 사용한다. 위치 정보로
  전기적 구획·전도 지연·수용체 효과를 모델링하지 않았으므로 모든 열이 계산에 쓰이지는 않는다.

## 모델의 가정

실측/공개 정보:
body ID, 연결 대상/방향, 시냅스 수, 주석, 좌우/종류, 일부 hex-column 위치,
전달물질 예측과 confidence. 원본을 수정하지 않는다.

모델링 가정:

- 입력은 L1/L2/L3 경계에 넣는다. 전체 모델의 광수용체 뉴런은 보존하지만 직접 자극하지 않는다.
  원본 광수용체에도 hex-column 위치 주석이 없어 완전한 눈 모델은 아니다.
- 단일 카메라를 좌우 영역으로 나누고 hex-column을 정규화한다. 좌표가 없는 입력 뉴런은
  해당 영상 영역의 평균을 받는다. 이 수량은 실행 metadata에 기록한다.
- L1/L2 시간 변화 강조, L3 시간 평균은 공학적 필터다.
- `h_next = leak*h + (1-leak)*max(0, tanh(gain*W*h + input))`.
  신경 활동은 음수가 없는 rate 가정이다. 음의 발화가 억제 신호의 부호를 뒤집는 것을 방지한다.
  기본 leak 0.65, gain 0.95. W는 시냅스 수를 postsynaptic 입력 합으로 정규화한다.
  `--weight-mode raw`는 정규화 없이 시냅스 수를 사용한다. 기본 gain에서는 활동이 포화될 수 있으므로
  gain도 명시하여 비교해야 한다. 예: `scripts/run_full_cns.cmd --weight-mode raw --gain 0.001`.
  이 값은 실측 연결 강도가 아니라 비교용 매개변수다.
- GABA −, ACh +라는 가정. Glutamate는 기본 +, 옵션으로 −를 비교한다.
  실제 수용체 정보가 없으므로 어느 쪽도 데이터로 확정된 효과가 아니다.
- 그 외 전달물질과 미주석 segment는 +의 구조적 전달을 사용하며, dopamine/serotonin 등
  neuromodulation이나 학습을 구현한 것이 아니다. 모든 예측 종류·confidence는 원본에 남긴다.
- 신경 업데이트는 물리 0.05초당 1회. 생물학적 시간에 맞춘 값이 아니다.
- 운동 출력은 위에 명시한 근육별 읽기와 힘·토크 변환이다. 생물학적 decoder와 근육 모델의 검증은 남아 있다.
- 현재 `models/full_cns_muscle_arena.xml`은 고정된 여섯 관절 진단 장치다.
  이전 두 바퀴 몸체 `models/full_cns_arena.xml`은 과거 기록용으로 남아 있다. 직사각형 두 다리는 아직 설계 전이다.
- 시각 외 감각 뉴런은 보존되지만 외부 접촉/고유수용성 입력을 받지 않는다.

모델이 멈춰 있거나 예상과 다르게 움직여도 신경 반응은 기록한다. 해당 모델의 결과이지
실제 초파리의 행동 능력이 없다는 결론이 아니다.

## 기록 후 필요한 부분 찾기

`simulation_logs/full_cns_날짜/`:

- `metadata.json`: 원본/모델 범위, 전달물질 가정, 파라미터, 입력 매핑.
- `annotations.feather`: 실행 당시 모든 뉴런 주석과 graph_index.
- `events.jsonl`: 조건, 시간, 신경 업데이트 번호, 근육별 원래 활동·활성·힘,
  관절별 토크·각도·속도, DNa02/DNg13 활동, 같은 시점의 무물체 기준 대비 변화, 계산 시간.
  `motor_commands`는 이제 6개 관절 토크(Nm)이며 좌우 바퀴 속도가 아니다.
  `output_mode`와 `motor_command_unit`으로 과거 기록과 구분한다. 고정 몸체의 `path_m=0`은 이동 평가값이 아니다.
- `frame_*.npz`: 모든 graph ID의 신경 상태, 카메라 영상, 시각 입력.
  활동이 드물면 0이 아닌 index와 값을 저장하며, 없는 index는 **정확히 0**이다.
  활동 ID가 전체의 1/3 이상이면 전체 float32 배열을 저장한다. 모두 무압축·무손실이며,
  반응 threshold나 상위 뉴런만 기록하는 방식이 아니다. 과거 압축 기록도 분석 도구에서 읽는다.
  새 기록에는 `leg_names`, `muscle_activity`, `muscle_activation`, `muscle_force_N`,
  `joint_torque_Nm`, `joint_angle_rad`도 들어간다. 그룹별 body ID는 metadata에 남긴다.

같은 실행에서 1번 neutral과 비교할 조건을 각각 충분히 관찰한 뒤 분석한다.

```powershell
python src/analyze_full_cns.py simulation_logs/full_cns_실행폴더 --case approach --reference neutral --top 2000
python src/analyze_full_cns.py simulation_logs/full_cns_실행폴더 --case approach --superclass vnc_motor --top 200
python src/analyze_full_cns.py simulation_logs/full_cns_실행폴더 --case approach --top 2000 --export circuit_extract/from_recording
```

`scripts/analyze_full_cns.cmd`에도 같은 인자를 넘길 수 있다. 기록 폴더를 끌어 놓으면 기본 free 분석.
평균 상태의 조건 간 차이를 기준으로 순위를 정하고 `analysis/ranked_responses.csv`에 저장한다.
neutral이 없으면 평균 활동 크기 순위라고 명시한다. `--after-seconds` 기본 2초 이후를 집계한다.
`--superclass`는 전체 모델 실행과 기록이 끝난 뒤 순위를 볼 범위만 제한한다.
조건별 관찰 시간과 자극을 맞춰야 비교가 의미 있다. 몸체가 움직이면 입력 변화가 섞일 수 있다.

`--export`는 선택한 graph ID 사이의 원본 연결을 추출한다. 중간 전달 신경이나 피드백이
누락될 수 있으므로 후보 부분망이지 기능이 검증된 최소 회로는 아니다.
그 결과를 작은 모델로 실행하여 반응이 유지되는지 검증하는 것은 이후 단계다.
실행 중 전체 graph 폴더를 덮어쓰지 않는다. 분석 시 원래 report와 같은지 확인한다.

개별 뉴런의 어느 입력 연결에서 신호가 들어왔는지 기록으로 역추적할 수도 있다.

```powershell
python src/trace_full_cns.py simulation_logs/full_cns_실행폴더 --frame 100 --body 12345
python src/trace_full_cns.py simulation_logs/full_cns_실행폴더 --frame 100 --body 12345 --synapses
```

`body`에는 실제 원본 body ID를 지정한다. 직전 기록과 원본 시냅스 수, 실행 당시 전달물질
가정을 사용해 연결별 기여를 CSV로 저장한다. 현재 기록과 재구성된 상태도 함께 저장한다.
모델 내부 신호의 분해이며 생물학적 인과관계 검증은 아니다.
`--synapses`는 원본 파트너 표를 순차 읽어 해당 뉴런으로 들어오는 개별 시냅스의 위치,
confidence, neuropil도 별도 CSV로 저장한다. 시냅스별 전달물질 표가 있으면 pre 좌표로
확률들을 연결하고, body 통계 표에서도 해당 뉴런과 입력 뉴런들의 pre/post 수 및 tracing
상태를 찾아 저장한다. 위치 표에서도 해당 뉴런의 모든 PreSyn/PostSyn 위치와 ROI·시각
column/layer 주석을 별도 CSV로 저장한다. 대형 원본을 읽으므로 시간이 걸린다.

## PC 비용과 검증 상태

전체 그래프에는 약 1.52억 원본 연결 행이 있다. 전체 구성은 여러 GB의 RAM과 작업 디스크를
사용하며, PC에서 실시간보다 느릴 수 있다. 제한된 모델로 자동 전환하지 않는다.
기록도 매 업데이트 전체 상태를 저장하므로 추가 시간이 든다. 압축 CPU 비용은 제거했지만
연결 계산과 디스크 쓰기는 여전히 실시간보다 느릴 수 있다. 콘솔에서 매 프레임 계산/저장 시간을 표시한다.
큰 초기 모델을 확보한 후 줄이는 전략이다.

사용자 요청에 따라 자동 테스트, 신경 동역학 실행, MuJoCo GUI 실행을 하지 않았다.
공개 데이터 다운로드, 원본 스키마 확인, 전체 그래프 인덱스 구성은 데이터 확보 작업이다.
