# TASS: 시각에서 다리 운동으로 이어지는 회로 추출

폴더 구성과 파일 위치는 [폴더 안내](docs/FOLDER_STRUCTURE.md)에 정리했다.
기본 실행은 루트의 `run_mujoco.cmd`이며, 나머지 실행·분석 스크립트는 `scripts/`에 있다.
Python 파일을 직접 실행할 때는 프로젝트 루트에서 `python src/파일명.py`를 사용한다.

GitHub에는 코드·설정·문서와 데이터 목록을 보관한다. 대용량 공개 데이터, 계산용 그래프,
수집 결과, 실험 기록 및 설치된 패키지는 `.gitignore`로 제외한다.
기존 NeuPrint 수집 코드 `src/find_CNS.py`의 인증 토큰은 `NEUPRINT_TOKEN` 환경변수로 제공한다.
공개 flat-connectome 다운로드는 이 토큰이 필요 없다.

현재 전략은 전체 공개 연결망으로 MuJoCo를 실행하고 **그 기록에서 필요한 회로를 추출**하는 것이다.
새 실행 파일은 `scripts/run_full_cns.cmd`. 데이터 범위·사용 방법·가정은 [FULL_CNS.md](docs/FULL_CNS.md)에 있다.
현재 실행은 **공개 NeuroMechFly 몸체 + 전체 CNS + 관절 토크 출력**이다.
초파리 형상, 자유 몸체, 여섯 다리의 66개 관절, 중력과 지면 접촉을 사용한다.
이 중 42개 관절에 출력 장치를 두고, 근육 기능 주석이 대응되는 관절만 신경 토크로 구동한다.
신경→근육 힘→관절 축의 변환은 아직 가정이며, 미대응 운동신경도 전체 계산·기록에 보존한다.
MuJoCo와 한국어 표시 창에서 몸체 이동·관절·발 접촉을 관찰한다.
`scripts/analyze_fly_recording.cmd`는 기록 분석, `scripts/replay_fly_recording.cmd`는 저장한 움직임의 재생 도구다.
이전 고정 경골 관찰 장치는 `scripts/run_muscle_rig.cmd`로 실행할 수 있다.
아래 제한된 회로와 두 바퀴 실험은 이전 단계의 기록이며 현재 기본 실행과 다르다.

카메라 하나와 초파리 연결지도 기반 동적 신경망을 이용해, 라즈베리파이 4 Model B에서
두 모터로 구동되는 직사각형 두 다리 로봇의 이동을 자율적으로 선택하는 것이 최종 목표다.
다리 기구는 미정이다. 초기 제어 실험에는 LLM을 넣지 않고 신경망의 기여를 관찰한다.
기존 L2→다리 회로 추출 및 여섯 다리 GUI는 보존한다. 현재 실험은 L1/L2/L3 입력과
전체 CNS의 반복 연결을 사용한다. 두 모터 로봇의 기구는 이후 별도로 설계한다.

## 이전 단계: 제한된 회로와 두 바퀴 몸체

이 단계는 **학습되지 않은 회로의 반응을 관찰하는 실험**이다. 자율 회피가 구현되었다고
가정하지 않는다. FLYNN의 재현도 아니다. FLYNN은 암컷 FAFB v783, 두 카메라, 목표 방향과
충돌 감각, DAgger 모방학습을 사용한다. 여기서는 기존 MaleCNS, 단일 카메라와 비학습 회로를
사용한다. 논문: https://arxiv.org/html/2607.00025v2

사용자가 실행할 순서:

1. `scripts/install_navigation.cmd`: 필요한 패키지 설치. 실행 중 외부 패키지를 다운로드한다.
2. `python src/prepare_navigation_circuit.py`와 `python src/mujoco_navigation.py`: 이전 제한 회로 실험을 실행한다.
   준비 과정은 대형 연결 테이블을 읽으므로 시간이 걸리고 상당한 메모리를 사용할 수 있다.
3. GUI는 일시정지로 시작한다. `Space` 시작/일시정지, `R` 원점 리셋,
   `B` RAW/BASELINE 전환 및 리셋, `C` 외부/로봇 카메라 전환.
4. 콘솔에서 좌우 하행 신경 활동, 이동 거리, 충돌 접촉 진입 횟수, 프레임 계산 시간을 확인한다.
   `simulation_logs/mujoco_*/frames.csv`와 `metadata.json`에 조건과 반응이 저장된다.
   `C`로 보는 화면이 실제 입력 카메라다. GUI 외부 시점은 제어 입력으로 사용하지 않는다.

일반 Python 환경에서는:

```powershell
python -m pip install -r requirements-navigation.txt
python src/prepare_navigation_circuit.py
python src/mujoco_navigation.py
```

### 회로와 영상 입력

- `src/prepare_navigation_circuit.py`는 주석이 있는 `ol_intrinsic`, `ol_sensory`,
  `visual_projection`, `visual_centrifugal`, `cb_intrinsic`, `descending_neuron`과
  관련 tbc 분류를 선택하고 이들 사이의 연결을 보존한다.
- 최소 연결 강도는 기본 5 synapses. `--min-weight 1`로 바꿀 수 있다.
- 순환·동일 층·역방향·자기 연결을 보존한다. 기존 8-hop 추출 결과를 사용하지 않는다.
- VNC와 미주석 segment, 다른 감각 입력 및 상행 피드백은 제외한다.
  따라서 **시각 전체 회로 또는 전체 CNS를 완전히 보존한 결과가 아니다.**
- L1/L2/L3에 한 이미지의 좌우 영역을 입력한다. hex-column 주석을 정규화하여
  픽셀에 대응시키는 임시 공간 매핑이며, 실제 눈의 투영 방향을 보정한 retinotopy가 아니다.
- L1은 밝기 증가, L2는 밝기 감소를 강조하고, L3는 시간 평균 밝기를 받는다.
  원본의 왼쪽 L3 880개에는 hex-column 좌표가 없다. 공간 좌표가 없는 L3에는
  해당 쪽 영상의 시간 평균 밝기를 공통 입력하며, 가정과 수량을 콘솔 및 metadata에 기록한다.
  좌표를 임의로 만들지 않는다. L1/L2 중 일부 좌표 누락 뉴런에는 직접 영상 입력을 주지 않는다.
  필터·누설·gain·4회 반복 업데이트는 공학적 가정이다. 생물학적 시간 단위로 해석하지 않는다.

### 두 모드의 의미

**RAW (기본):** 실제 선택된 반복 연결로 활동을 계산한다. 좌우 하행 신경의 평균 차이를
회전으로 읽고, 고정된 탐색 전진 속도를 준다. 전진 동기와 출력 해석은 사람이 지정한
가정이며, 개별 DN의 실제 조향 기능을 식별한 decoder가 아니다. 회피 규칙이나 학습은 없다.
정면 장애물에서 좌우 활동이 같으면 그대로 충돌할 수도 있다. 실패가 전체 생물 회로의
실패를 뜻하지 않으며, 입력·동역학·회로 범위·decoder 가정도 원인일 수 있다.

**BASELINE:** 카메라의 빨간 물체 픽셀을 보고 감속·회전하는 수작업 비교 규칙이다.
정면에서 좌우가 같으면 지정한 방향으로 회전한다. 이 모드의 회피는 신경망 성능이 아니다.
회색 벽을 포함한 일반 물체 검출기로 간주하지 않는다. 신경 반응은 기록하지만 모터에 사용하지 않는다.

장애물 좌표·깊이·충돌 정보는 어느 모드에서도 행동 입력으로 사용하지 않는다.
위치·접촉은 평가 기록에만 사용한다. 충돌 횟수는 접촉이 없는 상태에서 접촉으로 진입한
횟수이며 접촉이 반복되면 증가한다. 현재 목표 지점이 없으므로 목표 도달 성공률을 기록하지 않는다.

### 전달물질과 몸체의 한계

기본 `--nt structural`은 양수 연결 전달 실험이다. `--nt ach-gaba`는 ACh +,
GABA −, glutamate 및 다른/불명 전달물질 0이라는 보수적인 비교 가정이다.
전달물질 예측만으로 수용체 반응, 자율 행동, 학습된 연결 강도를 알 수 없다.

몸체는 높이를 고정한 두 바퀴 차동 구동 임시 모델이다. 두 velocity actuator와 접촉 마찰을
사용하고 5 mm 접촉 preload를 둔다. 두 직사각형 다리의 보행·균형을 검증하는 모델은 아니다.
프레임당 0.05초 물리를 진행하지만 계산이 느리면 벽시계 시간보다 시뮬레이션이 느려진다.
현재 회로가 라즈베리파이 4에 들어갈 크기·속도인지는 측정 전이다.

이 변경에서는 패키지 설치, 회로 준비, GUI 실행, 자동 테스트를 수행하지 않았다.

## 전체 데이터 기반 작업

공식 데이터: https://male-cns.janelia.org/download/

```powershell
python -m pip install -r requirements.txt
python src/download_connectome.py
python -m unittest discover -s tests -p test_circuit_extraction.py
python src/extract_visual_leg_circuit.py
```

이 작업에서 사용한 Python은 Codex의 번들 런타임이다. `pyarrow`와 `scipy`는 프로젝트 `.deps/`에
설치했다. 추출 스크립트는 해당 디렉터리가 있으면 사용한다. 일반 Python 환경에서는 위 명령으로
의존성을 설치하면 된다.

`src/download_connectome.py`는 토큰 없이 공개된 세 파일을 `data/male-cns-v1.0/`에 받는다.
파일 크기와 서버가 제공한 MD5를 확인하고 SHA-256, 원본 URL, 버전을 `manifest.json`에 기록한다.
기존 파일은 크기와 MD5를 확인해 재사용한다. 원본 Feather 파일은 수정하지 않는다.

## 추출 조건

- 출발점: 공식 주석의 `type == L2`인 모든 좌우 뉴런.
- 종착점: `superclass == vnc_motor`이고 `subclass`가 `fl`, `ml`, `hl`인 뉴런.
- 기본 연결 강도: `weight >= 1`. 공식 원본은 synapse confidence `minconf-0.5` 릴리스다.
- 연결 방향, 원본 body ID, 좌우 주석, 신경전달물질 정보, self connection을 보존한다.
- 전체 연결 테이블의 주석 없는 segment도 그래프에 포함한다.
- 시각 외 감각 뉴런은 이 단계에서 자동 삭제하지 않는다. 기능 판단과 피드백 보존 검토가 필요하다.

앞쪽 탐색은 L2에서의 도달 가능성을, 뒤쪽 탐색은 다리 운동 뉴런으로의 도달 가능성을 계산한다.
양쪽을 만족하는 노드와 내부 연결을 `unbounded/`에 저장한다. 순환을 허용하는 방향성 **walk**에
포함될 수 있는 구조이며, 모든 단순 경로의 목록이나 실제 작동이 입증된 최소 회로는 아니다.

`max_8_hops/`는 별도 탐색을 자르는 대신 전체 그래프에서 계산한 최단 거리로 필터링한다.
노드는 `L2에서의 거리 + 운동 뉴런까지의 거리 <= 8`, 연결은
`L2에서 source까지의 거리 + 1 + target에서 운동 뉴런까지의 거리 <= 8`을 만족해야 한다.
출발점/종착점의 조합은 고정하지 않으며, 여러 L2 및 여러 운동 뉴런 중 가장 가까운 것을 기준으로 한다.

## 결과

`circuit_extract/weight_1/`:

- `report.json`: 원본 출처, 조건, 규모, 분류 통계, 한계.
- `L2_sources.csv`: 각 L2의 그래프 포함 여부와 가장 가까운 다리 운동 뉴런까지의 거리.
- `leg_motor_targets.csv`: 각 다리 운동 뉴런의 주석, 그래프 포함 여부, L2로부터의 도달 여부와 거리.
- `unbounded/neurons.feather`: 전체 방향성 walk 연결망의 모든 노드와 주석.
- `unbounded/annotated_neurons.csv`: 같은 결과 중 뉴런 주석이 존재하는 노드.
- `unbounded/connections.feather`: 추출한 원본 연결 방향과 가중치.
- `max_8_hops/`: 최대 8단계 조건을 적용한 동일한 세 파일.
- `work/`: 대규모 그래프를 구성할 때 사용하는 디스크 기반 정수 인덱스.

Feather는 `pandas.read_feather()` 또는 `pyarrow.feather.read_table()`로 읽는다.
주석 없는 segment는 `has_neuron_annotation == False`로 구분된다. 이를 기능을 확인한 뉴런으로
해석해서는 안 된다. `from_L2_hops`와 `to_leg_motor_hops`는 연결 개수 기준 거리다.
신경전달물질 예측은 보존하지만 흥분/억제 효과나 수용체 반응을 임의로 지정하지 않는다.

조건을 비교하려면 별도 출력 디렉터리를 지정한다:

```powershell
python src/extract_visual_leg_circuit.py --min-weight 2 --max-hops 8 --output circuit_extract/weight_2
python src/extract_visual_leg_circuit.py --min-weight 5 --max-hops 6 --output circuit_extract/weight_5
```

현재 결과는 PC에서 회로를 검토하기 위한 후보 데이터다. 라즈베리파이에서 실행하는 모델,
모터 제어 코드, 실제 행동 검증은 포함하지 않는다. L2를 사용하는 가설과 다리 주석의 기능적
해석은 따로 검증해야 한다. 특히 추출 영역 밖의 운동 피드백 회로는 자동 보존되지 않는다.

## 가상 벽 GUI 실험

프로젝트 폴더의 PowerShell에서:

```powershell
.\scripts\run_simulation.cmd
```

`scripts/run_simulation.cmd`를 더블 클릭해도 된다. 로컬 서버가 켜지고 브라우저 GUI가 열린다.
서버가 실행되는 터미널은 열어둔다. 닫거나 Ctrl+C를 누르면 종료된다.
일반 Python 환경에서는 `python src/circuit_sim_gui.py`로도 시작할 수 있다.
GUI는 사용자가 시작 버튼을 눌러야 전달 단계를 실행한다. `시작 / 일시정지`, `한 단계 전달`,
`신경 상태 초기화`, `벽 보이기`, 벽 위치/거리, 출력 임계값을 조작할 수 있다.
가상 공간과 카메라 시야, 여섯 다리의 상대 반응, 신경망 규모를 표시한다.
실험 기록은 `simulation_logs/`에 저장한다. 물리적 모터에는 연결하지 않는다.

GUI는 `max_8_hops/`에서 주석 있는 뉴런을 사용한다. 입력은 단일 가상 카메라의 좌우 절반을
같은 쪽 L2 전체에 균일하게 매핑한다. 이는 실제 L2 수용장과 retinotopy를 복원한 매핑이 아니다.
원본 연결 중 `from_L2_hops`가 정확히 한 단계 증가하는 연결만 시뮬레이션에 사용한다.
따라서 순환/역방향 연결 및 주석 없는 조각은 GUI 모델에서 제외된다. 추출 원본에는 보존되어 있다.

모델은 뉴런별 입력 연결 가중치를 합으로 정규화하고 `새 상태 = 0.35 × 기존 상태 +
0.65 × 전달된 상태`를 계산한다. 한 단계는 실제 시간 단위가 아니다. 뉴런 발화/막전위 모델,
근육 및 접촉 물리, 실제 다리 들기 명령의 해독은 구현하지 않았다.
운동 뉴런 그룹의 평균 절대 반응을 모든 L2가 입력 1을 받는 기준 반응으로 나눠 시각화한다.
기준 반응이 거의 0인 그룹은 0으로 표시한다. 선택한 다리 표시 방식에 따라 각도를 연속적으로
그리며, 임계값은 강한 반응의 색상을 강조하는 데만 사용한다.
반응은 실제 연결을 계산해서 얻으며, 벽 유무로 다리 표시를 직접 전환하지 않는다.

기본 모드는 모든 연결을 양수로 취급해 구조적 전달을 확인한다. NT 가정 모드는
`consensus_nt`, `celltype_predicted_nt`, `predicted_nt` 순으로 이용해 ACh +, GABA −를 가정한다.
Glutamate는 기본 미정(0)이며 사용자가 + 또는 −를 명시적으로 선택할 수 있다.
그 외 전달물질은 0으로 차단한다. 수용체 의존성과 예측 오류가 있어 이 부호를 생물학적 확정값으로
해석하지 않는다. NT 가정 모드에서도 다리 표시는 절대 반응 크기이며 흥분성 운동 명령이 아니다.

이 실험은 파일/연결 계산과 입력 전달을 검토하는 데 사용한다. 벽 반응이 보인다고 정상 신경망이
입증되지는 않으며, 반응이 없다고 원본 연결 데이터가 잘못되었다고 결론내릴 수도 없다.

### 좌우 위치와 앞뒤 거리별 다리 표시

기본 다리 표시 방식은 `좌우·거리 표시 규칙`이다. 신경망의 정규화 반응에 별도의
좌우 계수와 거리 계수를 곱해 표시한다. `신경 반응 그대로`를 선택하면 이 계수를 적용하지 않는다.
각 다리 아래에 신경 반응과 표시 계수를 따로 보여주므로 둘을 비교할 수 있다.

- 벽이 왼쪽이면 왼쪽 다리에 높은 계수, 오른쪽이면 오른쪽 다리에 높은 계수를 준다.
  좌우 위치 -0.35 이하에서는 왼쪽만, +0.35 이상에서는 오른쪽만 표시한다.
  가운데 영역은 연속적으로 전환하고, 정확히 중앙이면 양쪽 계수가 0.5다.
- 앞다리는 거리 4.0, 중간다리는 2.6, 뒷다리는 1.5보다 가까워질 때부터 거리 계수가 증가한다.
  가상 거리 0.4에서 각 거리 계수는 최대다. 부드러운 곡선으로 변화시킨다.
- 들림 정도를 0–100%와 가상 각도 0–60°로 표시한다. 작은 반응도 연속적으로 그리며,
  강조 임계값은 색상을 바꾸는 데만 사용한다.
- 벽을 숨기면 기본 표시 규칙의 들림은 0이 된다. 신경 반응은 모델의 누설에 따라 따로 감소한다.

이 좌우/거리 패턴은 사용자가 지정한 표시 규칙이다. 연결망이 자체적으로 같은 패턴을 생성한다고
검증한 결과는 아니며, 실제 신경 반응이 0이면 표시 규칙만으로 다리를 들리지 않는다.
기록에는 원래 신경 반응, 적용 계수, 들림 각도와 선택한 표시 방식이 함께 저장된다.
이 수정은 코드 작성만 진행했으며 테스트와 실행은 진행하지 않았다.

python -m unittest discover -s tests
